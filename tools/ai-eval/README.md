# ai-eval — בדיקת שפיות לבונה המסלולים

מריץ תרחישי טיול אמיתיים מול `/api/ai/itinerary` של שרת חי, ומדווח מה חזר.
נועד להרצה **ביודעין** לפני שינוי בפרומפטים ואחריו — לא בכל commit.

```bash
node tools/ai-eval/run.js
```

## מה זה בודק

לכל תרחיש יש `expect` **מבני** בלבד: איזה ענף נכנס לפעולה, וכמה המסלול שיצא קוהרנטי
בתוך עצמו. אם האזורים רצופים, מכסים את כל טווח הימים בלי חורים, אף אזור לא חוזר
פעמיים, לכל יום יש תחנות, ויש תחנת נסיעה בכל יום שעוברים בו אזור — הבדיקה עוברת.

מה שהיא **לא** בודקת: אם "קנסאי (קיוטו, אוסקה)" היא אופציה טובה לטיול הזה. זו שאלה
של שיקול דעת, ולכן כל שאלה וכל תוכנית מודפסות במלואן — הן העיקר, לא ה-✓.

## הרצה

```bash
node tools/ai-eval/run.js                    # רק סבב ההבהרה — זול ומהיר
node tools/ai-eval/run.js --build            # גם בניית מסלולים מלאה — יקר
node tools/ai-eval/run.js japan-14-country   # תרחיש מסוים לפי id
node tools/ai-eval/run.js --runs 3           # כמה פעמים כל תרחיש
node tools/ai-eval/run.js --port 3000        # ברירת מחדל: PORT או 3000
```

צריך שרת שרץ (`preview_start`, או `npm start`) עם `OPENAI_API_KEY` ב-`.env`.
הטוקן נוצר בריצה מ-`JWT_SECRET` — אין צורך במשתמש אמיתי, והבנייה לא כותבת ל-DB.

## עלות

כל קריאה היא קריאת OpenAI אמיתית. סבב הבהרה הוא קריאה אחת קצרה (~2 שניות);
בנייה מלאה היא קריאה לכל אזור, עם `maxTokens` גבוה ולעיתים במודל החזק — טיול של
14 ימים בשלושה אזורים הוא שלוש קריאות כאלה. `--build` על כל התרחישים זה כמה עשרות
סנטים ודקה-שתיים. הריצה מדפיסה כמה בניות היא עומדת לעשות לפני שהיא מתחילה.

## התרחישים

ב-[cases.js](cases.js), כל אחד עם `why` שמסביר למה הוא קיים ואיזה כשל הוא שומר עליו.
כלל האצבע: **תרחיש נכנס רק אם הוא טיול שמישהו באמת יתכנן, ורק אם הוא נוגע בהחלטה
שאף תרחיש אחר לא נוגע בה.** שני טיולי מדינה קצרים הם תרחיש אחד, לא שניים.

הכיסוי כרגע — סבב הבהרה: מדינה ארוכה (שילוב אזורים), מדינה קצרה (התמקדות),
מדינה שהאזורים בה איים, שתי ערים ביבשת אחת, שתי ערים קרובות, מדינה שהוקלדה כטקסט
חופשי. בנייה: אזורים שנבחרו ידנית, שאלה שדולגה, קצב שנקבע מההערות, תחומי עניין
שמזיזים את האזורים, טיול דו-עירוני, ועיר בודדת.

## פלט

התוצאה המלאה נשמרת ל-`runs/<timestamp>.json` (לא בגיט). קוד יציאה 1 אם משהו נפל,
כדי שאפשר יהיה לשרשר.
